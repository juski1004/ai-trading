# AI 투자연구소 — 사업 전략·로드맵 (2026-10-25 초안)

> 사용자 지시: 스토어 앱 vs SNS+웹앱 결정, 게임+분석 결합의 문제 점검, 잘 되는 투자 앱 벤치마킹, 보완·생략 목록, 그 뒤 '최고의 프로그램'으로 개발.
> 이 문서는 ①벤치마킹 ②배포·수익 모델 ③현재 앱 비판 검토 ④결정 ⑤로드맵 순서.

## ③ 현재 앱 비판 검토 (2026-10-23 데이터, 휴대폰 화면 기준으로 직접 열어 확인)

### A. 법적 위험 — 가장 먼저 고칠 것
| 위치 | 지금 문구 | 문제 | 고칠 방향 |
|---|---|---|---|
| 홈·모든 화면 토스트 (advise.js) | "오늘의 추천 펄어비스, 1차 34,650원 **진입을 권합니다**. 손절…목표…" | 불특정 다수에게 특정 종목 매매를 권하는 문장. 광고·유료가 붙는 순간 유사투자자문업 신고 대상 소지 | "알파 팀이 **게임 계좌**에 담은 종목" + "참고 진입 구간"으로. '권합니다/권유' 단어 전부 제거 |
| advise.js 목표가·손절 알림 | "일부 **매도를 권합니다**", "분할 **매수를 권합니다**" | 같은 문제 | "게임 규칙(+10%)에 도달했어요 → 정리할지 선택" 식의 게임 안내문으로 |
| 종목 상세 | "매수 신호 2 · 매도 신호 7" | 매수/매도 표현 | "상승 신호 / 하락 신호" |
| 보고서·푸시 | "오늘의 추천 종목" | '추천' 자체가 조언 | "오늘 알파가 고른 종목(게임)" |
| 전체 | 면책 문구는 있음 (참고용·투자 권유 아님) | 유지 | 첫 실행 때 한 번 동의 받기 추가 |

원칙: **앱 안의 모든 종목 언급은 '게임 상대(알파)의 행동'이나 '데이터 요약'이어야 하고, 사용자에게 '하라'는 문장은 없어야 한다.**

### B. 사용성·재방문 (왜 내일 또 열까?)
- 토스트가 모든 화면에 계속 떠서 가림 (닫기 전까지). → 홈에서 한 번만, 다른 화면에선 종 버튼 숫자로.
- 게임 시작 화면이 비어 있음: 왜 해야 하는지, 남들은 어떤지 없음. → 지난 시즌 상위 수익률·알파 성적·"1분이면 시작" 예시.
- 하루 한 번 종가 매매라 장중엔 할 게 없음 → 이걸 약점이 아니라 **"하루 5분, 퇴근길 투자 게임"** 으로 포지셔닝. 매일 17:50 카드·18:00 브리핑·18:10 알파 매매가 '하루 한 번 오는 이유'.
- 출석·연속 기록·시즌(월간 리그)·배지가 없음 → 벤치마킹 결과에 따라 추가.
- 랭킹 서버는 떠 있지만 참여 0명, 화면은 '준비 중' 문구 → 실제 연결 확인 + 첫 참여 유도.
- 기록이 기기(localStorage)에만 → 폰 바꾸면 사라짐. 로그인 없이 '복구 코드' 또는 랭킹 id로 서버 백업.

### C. 데이터·신뢰
- 시세 15~20분 지연·하루 1회 갱신: 게임 규칙(종가 체결)과는 맞지만 '분석' 화면에선 현재가처럼 보임 → "10.23 종가" 표기를 가격 옆에 항상.
- AI 점수가 삼성전자 22점 '부정'처럼 직관과 어긋날 때 설명이 약함 → 점수 산식 한 줄·근거 3개 항상 노출.
- 뉴스 이유 문장("뚜렷한 개별 소식 없이…")이 반복돼 지루함 → 없으면 숨김.
- 분석 78종목, 거래 359종목 → 분석 대상 확대는 비용(LLM 호출)과 맞물림. 단계적으로.

### D. 생략·축소 후보
- 직원 '외모' 설명 문구 (내 정보): 정보 가치 낮음 → 접기.
- 홈 '옆으로 밀어서 넘겨 보세요' 카드 10장: 많음 → 5장 이내, 나머지는 '분석' 탭.
- PC HTS 화면(web/index.html)의 앱 내 iframe 중복: 앱 전용 차트로 대체 전까진 유지하되 메뉴 깊이 줄임.
