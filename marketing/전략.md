## 0. 제품 정의 (사용자 지시 2026-10-25)
**바쁜 직장인을 위한 '종가 스윙' 모의투자 프로그램.** 그날 장 마감 종가로 하루 한 번 판단하는 스윙 매매를 연습한다. 하루 종일 시세를 볼 필요가 없고, 장중 등락에 흔들리지 않는 원칙 매매가 장점.

문구 원칙: '못 해서'(장중에 못 본다·실시간이 어렵다)가 아니라 '이게 더 낫다'(하루 한 번이면 충분·흔들리지 않는다)로 쓴다. 약점처럼 들리는 표현 금지. 데이터는 실제 거래소 종가 그대로(2026-10-23 기준 삼성전자·SK하이닉스·삼성바이오·펄어비스·에코프로·카카오·코스피를 네이버 증권과 대조해 모두 일치). 이 설명을 사용법·게임 시작·동의 화면·약관·README·스토어 설명에 넣는다.

## 0-1. 한 줄 결정

**지금은 '웹앱(PWA) + 인스타 유입 + 광고'로 가고, 사용자 100명이 넘으면 플레이스토어(TWA)에 올리고, 유료는 '게임 편의 기능(프리미엄 패스)'만 판다. 종목 추천은 어떤 경우에도 돈 받고 팔지 않는다.**

| 질문 | 결정 | 이유 |
|---|---|---|
| 스토어 앱 vs SNS+웹앱 | **1단계 웹앱+SNS → 2단계 플레이스토어(TWA) → 3단계 iOS** | 사용자 0명 단계에선 스토어가 주는 이득이 없음: 개인 계정은 테스터 12명×14일이 필요하고, 애플은 웹 포장 앱을 자주 거절(4.2). TWA 안에선 AdMob도 못 씀. 웹앱은 비용 0, 지금 당장 인스타 링크로 들어올 수 있음 |
| 광고 | **애드센스(웹)** — 브리핑·카드뉴스 아카이브 페이지로 '콘텐츠 15편+' 요건 충족 후 신청 | 앱 UI만 있으면 '콘텐츠 불충분'으로 거절. 매일 쌓이는 장마감 브리핑이 곧 콘텐츠 |

## ① 벤치마킹 요약 (잘 되는 앱의 공통점)
1. **매일 돌아올 이유**가 있다 — 토스 틴즈 랜덤박스, Stock Trainer 보상형 광고, 마루랩 퀴즈→투자금.
2. **짧은 시즌 + 리그 분할** — 키움 영웅결정전(5개 리그, 2.3만 명), Invstr 월간 리그. 초보도 상위권이 가능해야 계속한다.
3. **학습과 보상 결합** — Bloom(강좌 완료→보상), 마루랩.
4. **실전으로 가는 출구** — 증권사 계좌 개설 제휴. 모의투자가 끝인 앱은 성장 상한이 낮다.
5. **체결 규칙이 투명** — 키움 모의투자의 최대 불만이 '체결 지연·비현실'. 우리는 "종가 체결·하루 한 번"을 숨기지 말고 규칙으로 내세운다.

실패 공통점: 가상돈을 돈 주고 사게 하기(반감), 리딩방화(핀업류·규제), 저평점 방치, 모의투자 뒤에 다음 행동이 없음(D30 이탈 99%).

우리 자리: 한국엔 **독립 모의투자 앱 중 규모 있는 곳이 사실상 없다**(증권사·토스가 미끼로 제공). "AI 직원 캐릭터 + 하루 5분 퇴근길 투자 게임 + 매일 브리핑"은 비어 있는 자리다.

## ③ 현재 앱 비판 검토 (휴대폰 화면 기준으로 직접 열어 확인)

### A. 법적 위험 — 가장 먼저 고칠 것
| 위치 | 지금 문구 | 고칠 방향 |
|---|---|---|
| 모든 화면 토스트 (advise.js) | "오늘의 추천 펄어비스, 1차 34,650원 **진입을 권합니다**" | "알파 팀이 오늘 **게임 계좌**에 담은 종목" + "참고 구간". '권합니다/권유/추천' 전부 제거 |
| 목표가·손절 알림 | "일부 **매도를 권합니다**", "분할 **매수를 권합니다**" | "게임 규칙(+10%)에 닿았어요. 정리할지 고르세요" 식 게임 안내 |
| 종목 상세 | "매수 신호 2 · 매도 신호 7" | "상승 신호 / 하락 신호" |
| 보고서·푸시·팀 소개 | "오늘의 추천 종목" | "오늘 알파가 고른 종목(게임)" |
| 첫 실행 | 면책 문구만 있음 | 위험고지·약관 **동의 한 번** (금감원이 토스 모의거래에 위험고지 부족을 지적) |
| 사이트 | 처리방침·약관 없음 | 페이지 추가 (스토어·애드센스 모두 URL 필수) |

원칙: **앱 안의 모든 종목 언급은 '게임 상대(알파)의 행동' 또는 '데이터 요약'이고, 사용자에게 '하라'는 문장은 없다.**

### B. 재방문·사용성
- 토스트가 모든 화면에 계속 떠서 가림 → 홈에서 한 번, 다른 화면은 종 버튼 숫자만.
- 매일 올 이유가 푸시뿐 → **출석(연속 기록)·연구소 포인트·캐릭터 해금·월간 시즌 리그** 추가.
- 게임 시작 화면이 비어 있음 → 알파 성적·"1분이면 시작"·규칙 3줄.
- 하루 한 번 종가 매매 = 약점이 아니라 **"하루 5분 퇴근길 투자 게임"** 으로 내세움 (17:50 카드 → 18:00 브리핑 → 18:10 알파 매매가 하루 한 번 오는 이유).
- 기록이 기기에만 → 폰 바꾸면 사라짐. 랭킹 id로 서버 백업(프리미엄 항목 후보).
- 랭킹 서버는 떠 있으나 참여 0 → 시즌과 함께 첫 참여 유도.

### C. 데이터·신뢰
- 시세 15~20분 지연·하루 1회 → 가격 옆에 항상 "10.23 종가" 표기, 체결 규칙 화면에 고정.
- AI 점수가 직관과 어긋날 때(삼성전자 22점) 근거가 약함 → 근거 3개 항상 노출.
- "뚜렷한 개별 소식 없이…" 반복 → 없으면 숨김.

### D. 생략·축소
- 직원 '외모' 문구 접기 · 홈 카드 10장 → 5장 · PC 화면 iframe은 앱 전용 차트 전까지 유지.

| 방법 | 판정 |
|---|---|
| 카드 마지막 장 설치 유도 | 안 함. 인스타 카드엔 누를 링크가 없어 전환이 낮음. 마지막 장은 '팔로우하고 내일도 받아보기' |

| 애드센스 | archive/ 글 15편 뒤 신청 (11월 중순), 앱 화면엔 광고 안 넣음 |
