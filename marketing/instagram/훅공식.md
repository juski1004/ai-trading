# 첫 2초 훅 공식 26개 (한국어) — 투자연구소 릴스·깡통 쇼츠 공용

출처: 공개 저장소 Jakeschincariol/instagram-agent-skill (MIT)의 영어 공식 26개를 한국어 채널에 맞게 옮김 (2026-11-01 사용자 지시).
쓰는 법: 릴스·쇼츠 첫 문장을 고를 때 아래에서 어울리는 공식 1개를 골라 채우고, 말하는 문장과 화면 글자를 따로 쓴다.

## 공통 규칙
1. 말하는 문장은 2초 안, 화면 글자는 6단어 이하(읽는 데 1초).
2. 도입·인사 없이 "6초째에 하려던 말"부터 시작한다.
3. 숫자를 말한다. "많이"·"엄청"은 숫자가 아니다.
4. 첫 화면에 움직임이나 글자가 있어야 한다(정지 화면 금지).
5. 다른 곳에도 그대로 쓸 수 있는 훅이면 우리 훅이 아니다. 우리만 말할 수 있는 것(우리 데이터·판정)을 넣는다.
6. 투자연구소: 추천·권유 문구 금지(신호·참고, 투자 권유 아님). 깡통: 결론(진짜/가짜)을 첫 문장에서 말하지 않는다.

## 공식 (빈칸 채우기)
| # | 공식 | 쓰임 |
|---|---|---|
| 1 | {구체적 금액} 날렸습니다, {실수 하나} 때문에 | 실패담 |
| 2 | {흔한 행동} 그만하세요. 대신 {대안} | 반대 주장 |
| 3 | 아무도 안 알려주는데, {불편한 진실} | 폭로 |
| 4 | {이것} 하나가 {비싼 것}을 {가격}에 대체했습니다 | 가성비 |
| 5 | 예전엔 {긴 시간} 걸렸는데 이제 {짧은 시간} | 시간 절약 |
| 6 | {N일} 해봤습니다. 진짜 숫자입니다 | 실험 결과 |
| 7 | {행동} 잘못하고 계신 겁니다, 당신 탓 아니에요. 해결법 | 공감+해결 |
| 8 | {N년} {그 업계}에 있으면서 말 못 한 것 | 내부자 |
| 9 | 가져가세요, {결과물}. 만드는 데 {시간} 걸렸어요 | 무료 제공 |
| 10 | {구체적 상황}이라면, {짧은 시간}이면 끝납니다 | 타깃 지정 |
| 11 | {N}가지 {것들}, {k}번이 아무도 안 쓰는 겁니다 | 목록 |
| 12 | "{실제로 듣는 반박}" 맞아요. 그래도 이게 통하는 방법 | 반박 |
| 13 | (예전 모습) → (지금 모습) → 한 문장 설명 | 전후 비교 |
| 14 | {특정 집단}, 이것만은 놓치고 계세요 | 호명 |
| 15 | {N번} 해봤는데 안 됐습니다. {N+1}번째에 바뀐 것 | 시행착오 |
| 16 | "{실제 질문 그대로}" — 매주 받는 질문입니다 | 질문 응답 |
| 17 | {A} 대 {B}, {기간} 돌려봤더니 한쪽이 압도적 | 비교 |
| 18 | (이미 하는 중에서 시작) 이게 뭘 하는지 보세요 | 장면 시작 |
| 19 | {것}이 {날짜}에 바뀝니다. 그 전에 {행동} | 마감 |
| 20 | {모두가 필요하다는 것}, 필요 없습니다 | 통념 뒤집기 |
| 21 | (…그리고 그때 {반전}) | 중간 시작 |
| 22 | {유명한 말}을 거꾸로 | 뒤집기 |
| 23 | {집단}의 {N}%가 {의외의 사실} | 통계 |
| 24 | 이게 새로운 {것}입니다 | 신제품 |
| 25 | {시간} 만에 {결과}를 낸 {사람} 한 명 | 사례 |
| 26 | 가장 {빠른·큰·유일한} {것}의 답은 {정답} | 단정 |

## 우리 채널 우선 후보
- 투자연구소(릴스): 23(통계), 17(비교), 3(폭로), 20(통념 뒤집기), 19(마감) — 예: "코스피 {N}% 빠진 날, 외국인이 산 종목은 {N}개뿐"
- 깡통(쇼츠): 16(질문), 12(반박), 3(폭로), 25(사례), 18(장면 시작) — 예: "이 영상 1,200만 명이 봤는데, 진짜일까요?"
