# AI 투자연구소 인스타 채널 운영 규칙

깡통 채널(뻥이야 진짜야)에서 효과 본 규칙을 그대로 가져와 주식 채널에 맞게 고쳤다.

## 1. 채널 설정 (처음 한 번)

| 항목 | 내용 |
|---|---|
| 계정 | 새 인스타 계정 → **프로페셔널(크리에이터) 계정**으로 전환 → 페이스북 페이지 연결 (자동 업로드에 필요) |
| 아이디 | 짧고 검색되는 것. 예: `ai.tooja.lab` / `ai_jusik_lab` |
| 이름 칸 | `AI 투자연구소 · 오늘 장마감 1분 요약` (이름 칸도 검색에 걸림 → 핵심어 넣기) |
| 소개 첫 줄 | `평일 18시 반, 코스피·코스닥 장마감 1분 요약` |
| 소개 둘째 줄 | `AI 직원 6명이 하루씩 진행 · 가상 1,000만 원 모의투자 무료` |
| 소개 셋째 줄 | `참고용 · 투자 권유 아님` |
| 프로필 링크 | `https://juski1004.github.io/ai-trading/app/` (앱 바로 열림) |
| 프로필 사진 | 앱 아이콘 (얼굴 아님 → 진행자가 매일 바뀌어도 어색하지 않게) |
| 댓글 필터 | 설정 → 숨겨진 단어 켜기 + 막을 단어: `리딩방, 종목추천방, 수익보장, 텔레그램, 오픈채팅, 카톡방, 무료추천, 급등주 알려` |
| 비즈니스 이메일 | 연락처 버튼에 이메일만 (전화번호 X) |

## 2. 카드뉴스 (자동)

- 평일 데이터 갱신 때 `ai_trading/data/cards.py` 가 6장 + 캡션을 만든다 → 사이트 `data/cards/` 에 올라감.
- **진행자: 직원 6명이 하루에 한 명씩** (윤시아 → 서하린 → 차유나 → 민채원 → 강도윤 → 한예린 → 다시 윤시아). 본부장 얼굴은 안 나온다.
  - 표지(훅): "○○가 알려주는 10월 27일 장마감 현황" + 진행자 사진 크게, 2~5장 오른쪽 위에 작게, 6장에 "오늘 진행은 ○○ · 내일은 ○○ 차례".
  - 주말은 건너뛰고 거래일 기준으로 다음 사람.
- 숫자는 데이터 그대로만 쓴다 (AI 문장은 숫자를 틀릴 수 있어 안 씀). 모든 장 아래 `참고용, 투자 권유 아님`.
- 특정 종목을 "사라/팔아라"로 쓰지 않는다 (유사투자자문 문제). 오른 종목·내린 종목은 사실과 그날 기사 제목만.

## 3. 업로드 시간

- **월~금 18:31** (장 마감 15:30 → 데이터 갱신 ~17:45 → 퇴근길 18시 반).
- 매번 같은 시간. 그날 데이터가 안 만들어졌으면(휴장일·실패) 올리지 않는다.

## 4. 구독자(팔로워) 늘리는 규칙 — 깡통에서 가져옴

1. **첫 줄에 검색어**: 캡션 첫 줄 = `윤시아가 알려주는 10월 27일 장마감 현황 | 오늘 주식 장마감 요약 · 코스피 +0.3%`. 인스타는 캡션 첫 줄을 검색에 쓴다.
2. **해시태그 = 고정 8개 + 그날 화제 2~3개 + 유행 3~5개**
   - 고정: `#주식 #코스피 #코스닥 #장마감 #주식공부 #모의투자 #재테크 #AI투자`
   - 그날 화제: 많이 오른·내린 종목명 (`#삼성전자` `#에코프로`)
   - 유행: 그 주 많이 검색된 경제 단어 (`#금리인하` `#환율` 등). **정치 단어는 넣지 않는다.**
3. **올리고 바로 댓글 하나**: "내일 오를 것 같은 종목 댓글로! 맞히면 다음 카드에 소개해요" → 사용자가 고정.
4. **진행자 시리즈**: "내일은 ○○ 차례" 로 다음 날 다시 보게 만든다. 반응 좋은 진행자는 메모해 둠.
5. **48시간 확인**: 올린 지 이틀 뒤 저장·공유·도달 확인. 기준: 저장 수가 좋아요의 10% 이상이면 잘 된 편.
6. **막힌 주엔 실험 하나만**: 표지 문구, 진행자 사진 크기, 업로드 시간 중 **하나만** 바꿔 본다. 잘 되면 고정.
7. **월요일 숫자 점검**: 팔로워 수, 지난주 도달·저장 상위 2개, 프로필 링크 클릭 수 → `marketing/instagram/주간기록.md` 에 한 줄.
8. **돈 쓰지 않기**: 반응이 붙기 전엔 광고·유료 도구 새로 쓰지 않는다.
9. **깡통 채널과 서로 소개하지 않는다** (주제가 달라 팔로워가 섞이면 도달이 떨어짐).

## 5. 사람이 해야 하는 것 (자동으로 못 함)

- 새 인스타 계정 만들기, 프로페셔널 전환, 페이스북 페이지 연결
- 미라(Mirra)에 새 계정 연결 → 연결되면 클라우드 통합방에서 평일 18:31 자동 업로드 예약을 건다
- 첫 댓글 고정 (앱에서 길게 누르기 → 고정)
