# ai-trading

장중에 실시간 매매가 어려운 **직장인을 위한 종가 스윙 모의투자 게임**. 그날 장 마감 종가로 하루 한 번 사고팔며, AI 6명이 실제 시세로 코스피·코스닥 주식을 분석하고 **가상 계좌**에서 자동매매한다.
시세·지수는 거래소 종가 그대로(네이버 증권과 같은 값, 2026-10-23 6종목+코스피 대조 확인). 진짜 돈은 쓰지 않는다. 투자 권유가 아니다.

| AI | 역할 |
|---|---|
| JOY | 시장·거시경제 (지수 흐름 + 환율·유가·금리·VIX) |
| OSCAR | 수급·뉴스 (거래량·가격 + 최근 뉴스·공시) |
| RAY | 차트 분석 (이동평균, MACD, RSI) |
| MILES | 진입 계획 (진입가·손절가·목표가·수량) |
| LLOYD | 리스크 점검 |
| THEO | 의견을 모아 최종 판정 (Gemini 무료 등급, 실패 시 규칙) |

## 게임 규칙 (`ai_trading/config.py`)
- 시작 자금 1,000만 원, 투자 기간 7~90일, 스윙 매매(하루 한 번)
- 분석 대상: 코스피·코스닥 대형주 78종목 (`ai_trading/data/universe.py`, `AI_UNIVERSE` 환경변수로 변경)
- 자동 손절 −5%, 자동 익절 +10%
- 한 종목 최대 20%, 최대 5종목, 하루 −3% 손실 시 그날 신규 매수 중지
- 수수료·거래세·미끄러짐 반영

## 앱: AI 투자연구소 (`web/app/`, 휴대폰용 웹앱)
종목분석기 + 모의투자 게임을 합친 무료 웹앱. 휴대폰 홈 화면에 추가하면 앱처럼 쓸 수 있다.
- 주소: `https://juski1004.github.io/ai-trading/app/`
- 홈: 오늘의 시장(코스피·코스닥·원/달러), AI 점수 상위 종목, 거래량 급증 종목
- 분석: 대형주 목록(긍정/중립/부정 필터)·검색, 종목 상세(6개월 차트, AI 종합 점수 100점, 참고 목표가·손절가, 재무·기술 점수 5점, 리스크, 뉴스 AI 요약, AI 분석팀 의견, 재무 지표, 기술 지표 12개)
- 투자게임·내 정보 탭은 다음 단계에서 채움
- 데이터: `data/scores.json` (`ai_trading/data/scores.py`, 데이터 갱신 때 함께 생성). 앱에서는 매수/매도 대신 긍정/중립/부정 + 100점 점수로 표시 (참고용)

## 화면: AI 트레이딩 아레나 (`web/index.html`)
증권사 HTS 같은 화면에서 **최근 90거래일 실제 데이터를 하루씩 다시 재생**하며 나와 AI 운용팀이 같은 1,000만 원으로 겨룬다.
- 맨 위 **종목 진단 카드**: 목표가·손절가, 재무 점수·기술 점수(5점), 리스크, 최근 뉴스 AI 3줄 요약(Gemini)
- 일봉 차트, 보조지표 18종과 설정, 기술적 지표 요약, 호가 모양
- 경제지표(원/달러, 달러인덱스, WTI, 금, 미국 10년물, VIX, 한·미 물가, 한·미 기준금리)
- 뉴스·공시·경제 일정, 분기 실적·PER·PBR·ROE·부채비율·배당
- 코스피·코스닥 전 종목 검색 (차트와 대결은 분석 대상 종목만)
- 실전 AI 계좌: 엔진이 실제로 매매 중인 가상 계좌 기록
- 직원 사진은 AI로 만든 가상 인물이다.

| 항목 | 출처 | 키 |
|---|---|---|

| 종목 목록 | KRX 상장법인목록(KIND) | 필요 없음 |
| 분기 실적·자본·부채 | 야후 파이낸스 (발표일은 분기 말+30일로 추정) | 필요 없음 |
| 뉴스 헤드라인 | 구글 뉴스 RSS (제목·링크만) | 필요 없음 |
| 미국 물가·기준금리 | FRED | `FRED_API_KEY` (없으면 공개 CSV) |
| 한국 물가·기준금리 | 한국은행 ECOS | `ECOS_API_KEY` (없으면 최근 10건만) |
| 공시 | DART OpenAPI | `DART_API_KEY` (없으면 공시 생략) |
| AI 비상용 1 (Gemini 실패 시) | Groq 무료 등급 (Llama) | `GROQ_API_KEY` (선택) |
| AI 비상용 2 | xAI Grok (유료) | `XAI_API_KEY` (선택) |
| 뉴스 3줄 요약 | Gemini 무료 등급 (소식 많은 40종목) | `GEMINI_API_KEY` (없으면 헤드라인만) |

키는 **Settings → Secrets and variables → Actions → New repository secret** 에 위 이름으로 넣는다. 화면이나 커밋에는 절대 들어가지 않는다.

## 자동 실행 (`.github/workflows/trade.yml`)
- 평일 장중 09:47 / 11:47 / 13:47 / 14:47 KST에 시도, 그날 처음 성공한 한 번만 매매 (`cycle`), 판정은 `game/verdicts.json`
- 평일 16:07 KST (밀리면 16:47 한 번 더): 화면 데이터·인스타 카드뉴스 갱신 (`data`) → 화면과 데이터를 `site` 브랜치에 덮어써서 올림 (기록이 쌓이지 않음)
- 수동: Actions → "AI 모의투자 게임" → Run workflow → `start` / `cycle` / `report` / `data`

## 자동 점검과 알림 (Claude 없이도 돌아가게)
- 모든 실행은 GitHub Actions(무료)에서 돌고, 화면은 GitHub Pages(무료)로 나간다. Claude는 고칠 때만 필요하다.
- **데이터 점검**: 장 마감 후 갱신 때 `python -m ai_trading.data.health web/data` 가 빈 칸·오래된 시세·AI(Gemini) 실패·수급·공시·키 만료를 찾는다.
- **알림**: 문제가 있으면 `자동점검` 이슈가 열리고(GitHub가 메일로 보냄), 다음 점검에서 문제가 없어지면 저절로 닫힌다. 실행 자체가 실패해도 같은 이슈에 알린다.
- **60일 멈춤 방지**: 공개 저장소는 60일 동안 활동이 없으면 예약 실행이 꺼지므로, 매 실행 끝에 워크플로를 다시 켜 둔다.
- **사람이 할 일**: 한국은행 ECOS 키는 만료일이 있어 만료 전에 연장한다. 무료 출처(야후·네이버)가 바뀌어 이슈가 계속 열려 있으면 코드 수정이 필요하다.

## 실행
```bash
pip install -r requirements.txt
python -m pytest
python -m ai_trading.data.export --out web/data   # 화면 데이터 만들기 (5분 정도)
python -m http.server 8765 --directory web        # http://localhost:8765 에서 화면 보기
python -m ai_trading.team 005930.KS               # AI 6명 분석
python -m ai_trading.run start --days 30
python -m ai_trading.run cycle
python -m ai_trading.run report
```
